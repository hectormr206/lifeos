# Axi

Local-first voice assistant module of LifeOS. MVP: push-to-talk dictation
(Super+Space) → faster-whisper → clipboard + KDE notification.

Built on PipeWire, runs entirely offline. Hardware target: laptop with NVIDIA
GPU (12 GB VRAM) on CachyOS / KDE Plasma Wayland.

## Status

Pre-alpha. MVP in active construction.
